# Section 3: AI Prompting & Charting Challenge — Prompt Log (`PROMPT_LOG.md`)

This document records the interaction with the AI assistant to create the `matplotlib` telemetry bar chart visualization, detailing the initial prompt, the defects identified in the first draft, and the corrective follow-up prompt.

---

## 1. Initial Prompt to the AI

```text
Write a Python script using matplotlib that loads an aggregated telemetry JSON file 
(containing objects with "device_id" and "average_temperature") and creates a bar chart 
comparing the average temperature per device. Save the resulting chart as a PNG file.
```

---

## 2. Defects & Issues in the AI's First Attempt

Upon running and inspecting the initial code generated by the AI assistant, the following formatting and layout bugs were discovered:

1. **Y-Axis Label Truncation & Clipping:**
   - The AI set default axes without adding upper headroom on the Y-axis. When data labels (e.g. `72.40 °C`) were printed directly on top of the bars, the text on the tallest bar (`DEV_B`) collided with and got clipped by the top border of the figure.
2. **Missing Safety Threshold Reference:**
   - The chart lacked a visual marker for the operational limit ($80.0^\circ\text{C}$), making it difficult for an operator to see how close devices were to the cutoff threshold.
3. **Headless Execution Warning:**
   - The script invoked default GUI interactive plotting backends without specifying `matplotlib.use("Agg")`, causing unnecessary overhead and warning messages in headless CLI environments.
4. **Poor Contrast & Alignment:**
   - Bars used generic plain colors without explicit edges or value annotations, and labels were crowded on narrow windows.

---

## 3. Follow-up Corrective Prompt

```text
The initial script works, but has layout and design issues:
1. The numeric value labels above the tallest bars get clipped by the top edge of the figure. Please expand ax.set_ylim() to provide 20% headroom above the maximum temperature.
2. Add a horizontal dashed reference line at 80.0 °C in red with a legend entry: "Max Permitted Threshold (80 °C)" so operators can evaluate safety limits.
3. Configure matplotlib to use the non-interactive "Agg" backend so the script runs cleanly in headless CLI and automated pipeline environments.
4. Add data value labels (e.g., "XX.XX °C") centered neatly above each bar, with a subtle background grid on the Y-axis and tight layout.
```

---

## 4. Final Result & Verification

- **Code:** Implemented cleanly in `visualizer.py`.
- **Output:** `temperature_chart.png` is generated at 300 DPI, with centered numeric badges, adequate top padding, an $80.0^\circ\text{C}$ threshold reference line, and `plt.tight_layout()` ensuring zero label clipping.
